# Age Calculator

A beginner-friendly age calculator built with React Native, Expo, and Expo Router.

## Features

- Exact age in years, months, and days
- Total months, weeks, days, hours, and minutes
- Leap-year and future-date handling
- Next birthday countdown and zodiac sign
- Persistent calculation history with AsyncStorage
- Light mode, dark mode, and system theme
- Home, History, and Settings tabs

## Run the app

```bash
npm install
npx expo start
```

Press `w` for the web version, or scan the QR code with Expo Go.

## Project structure

```text
src/
   app/              Expo Router screens
   components/       Reusable UI components
   context/          Theme and history state
   utils/            Age calculation logic
assets/             App, splash, and tab icons
```
